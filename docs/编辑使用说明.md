# 文章发布说明（给编辑）

在这里发布的文章，会出现在网站的「人工智能与观点」栏目：drkervis.com/insights/

## 登录

1. 打开 **drkervis.com/admin/**
2. 输入管理密码，点「登录」。
3. 用完后点右上角的「退出登录」。登录 12 小时后会自动退出。

## 发布一篇新文章

1. 点「**新建文章**」。
2. **文章标题**：写文章的标题。
3. **文章内容**：把整篇文章粘贴进来。
   - 从 **Word、Google 文档、ChatGPT** 复制的文章，**大标题、小标题和要点会自动识别**，
     粘贴后会提示「已按格式转换」，请检查一下标题对不对。（加粗的短句会当作小标题。）
   - 自己写的话：
     - **大标题**：这一行最前面写 `## `（两个井号加一个空格），例如：`## 第一个大标题`。大标题会出现在文章左边的阅读导航里。
     - **小标题**：这一行最前面写 `### `（三个井号加一个空格），它显示在大标题下面。
     - **要点**：这一行最前面写 `- `（一个短横线加一个空格）。
     - 其余**每一行都是一段**正文。
   - 如果是从记事本等纯文字复制的，没有格式可以识别，需要自己加上 `##`、`###`。
4. **文章图片**：点「选择图片」，选一张照片。系统会自动缩小，不需要自己处理。**必须上传图片。**
5. **英文网址会自动生成**：标题和内容都填好后，标题下面会显示「文章网址：drkervis.com/insights/……/」，
   系统会自动补上英文网址（同时补上空着的摘要和搜索设置）。想改的话，展开「摘要与搜索设置」，自己输入的网址不会被覆盖。
   也可以点「**自动生成摘要和搜索设置**」重新生成。不管点不点，发布时都会自动补上。
6. 点「**发布文章**」。

看到「已发布……大约 1 分钟后会出现在网站上」就成功了。请等 1 分钟，再点「查看」。

## 修改或删除

- 点文章右边的「**编辑**」，改好后点「保存修改」。文章的网址和发布日期不会变。不换图片的话，不用重新选图片。
- 点「**删除**」会再问一次。确认后，大约 1 分钟内文章会从网站消失，**而且无法恢复**。

## 小提醒

- 内容请确认事实准确，涉及人物、数字、头衔、奖项的话，请写有依据的内容。
- 写了一半不想要了，点「取消」，系统会先问你一次，避免误关。
- 列表里图片显示「图片稍后显示」是正常的：网站更新需要大约 1 分钟，过一会儿会自动出现。

## 遇到问题

| 看到的提示 | 怎么办 |
|-----------|--------|
| 密码不正确 | 重新输入。连续输错 8 次会被暂时锁住，15 分钟后再试 |
| 登录已过期，请重新登录 | 重新登录。刚才写的内容不会自动保存，登录后请重新发布 |
| 这个网址已被使用 | 在「摘要与搜索设置」里把「网址」改一个（只能用小写英文字母、数字和连字符 -） |
| 图片太大 / 图片格式不支持 | 换一张 JPG、PNG 或 WebP 图片 |
| 操作没有成功 | 等一会儿再试一次。一直失败，请联系网站管理员 |
